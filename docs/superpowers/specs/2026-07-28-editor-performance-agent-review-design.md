# 编辑器性能与Agent审阅设计

## 目标

- 缩短管理端笔记编辑器首次可用时间，保留代码块、LaTeX、表格和图片等现有能力。
- 让Agent基于全文或选区生成修改建议，用户确认前不修改正文。
- 防止正文变化后旧建议按过期坐标覆盖新内容。

## 编辑器资源

Milkdown Crepe默认静态引用`@codemirror/language-data`，使全部语言描述进入编辑器主依赖图。代码解析器虽已按语言拆包，但主包仍携带无用语言目录。

新增本地CodeMirror语言目录，并通过Vite alias替换`@codemirror/language-data`。目录只导出：

- JavaScript与TypeScript
- Python
- Shell
- SQL
- JSON
- HTML与CSS
- Markdown

Milkdown继续启用CodeMirror和LaTeX，不禁用任何现有编辑功能。若别名方案造成循环依赖、构建体积上升或运行异常，则停止该方案，不以拆包数量代替实际体积收益。

## Agent审阅

### 上下文

Agent请求继续携带标题、摘要、正文、选区和有限历史。创建请求时，编辑器桥接层同时保存：

- 唯一审阅ID
- 修改范围：选区或全文
- 原始Markdown
- 原始正文快照
- ProseMirror范围坐标

Agent不能直接调用编辑器写入接口。

### 展示

修改建议在编辑器内以文内替换块呈现：

- 删除内容使用弱红色删除标记
- 新内容使用弱绿色新增标记
- 右上角使用`✕`和`✓`图标按钮
- 图标提供“放弃修改”和“接纳修改”提示

不新增第二套弹窗或长篇说明。

### 接纳

用户点击`✓`时，桥接层重新读取当前正文：

1. 当前正文与请求快照一致：通过单个ProseMirror transaction写入建议。
2. 当前正文已变化：拒绝写入，关闭旧审阅并提示重新生成。
3. 选区坐标越界或审阅ID失效：拒绝写入，不修改正文。

写入成功后同步隐藏Markdown字段并标记为未保存，由现有保存流程持久化。

### 放弃

用户点击`✕`或按`Escape`时关闭审阅，不修改正文，不改变保存状态。

## 安全与边界

- 加密笔记未解锁时，Agent不能读取正文或选区。
- 服务端继续限制正文、选区、消息和历史长度。
- 同一时间只允许一个活动审阅，后生成的建议替换旧审阅。
- 第一版不持久化Agent建议，不新增数据库表。

## 验收

- 生产构建成功，编辑器主JS的原始大小和gzip大小均低于当前基线约`1488KB / 471KB`。
- 常用语言代码块、LaTeX、表格、图片和Markdown编辑正常。
- 全文与选区建议均先审阅后写入。
- 接纳、放弃、正文变化冲突、坐标失效和加密笔记限制均有自动化测试。
- 浏览器验证编辑器可加载、审阅区可滚动、图标可操作且正文不会被未确认修改。
